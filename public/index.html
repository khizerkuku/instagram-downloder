Frequently Asked Questions

Which platforms and formats are supported?

Instagram (Reels, Posts, Carousels, IGTV), TikTok (Without Watermark + MP3), Facebook (Videos, Reels, fb.watch), Snapchat (Spotlight & public Stories), and an inline Public Media Viewer mode.

How does the Viewers option work?

Selecting Viewers resolves the public link so you can watch the video, inspect thumbnails, creator handle, and caption right inside the page without immediately triggering a file download.

Are private accounts supported?

No. Only publicly accessible links are supported, and optional Worker API secrets (RAPIDAPI_KEY, TIKTOK_RAPIDAPI_KEY, FACEBOOK_RAPIDAPI_KEY, SNAPCHAT_RAPIDAPI_KEY) can be configured for reliable production traffic.
